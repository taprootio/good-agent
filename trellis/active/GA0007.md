# GA0007 — Remove the work-task playbook from Trellis in favour of good-agent

## Scope

The work lands in the Trellis repository (`../trellis`); this task tracks
it from here. Owner decision, 2026-11-01: Trellis keeps the backlog
lifecycle and good-agent owns the working and reviewing loop.

- Delete `trellis/playbooks/work-task.md` and the `work-task` MCP prompt in
  `src/prompts.mjs`; keep `code-review.md` and `pr-draft.md` but have the
  review step defer to good-agent's `review-loop` skill when installed.
- `trellis init` stops scaffolding `work-task.md` and instead writes one
  line in the Trellis block of AGENTS.md pointing at good-agent's
  `work-task` skill for working a task (`npx good-agent init --skill`).
- Trellis's own AGENTS.md "Working here" bullet points at good-agent's
  skills; Trellis adopts the guard in CI.
- `SPEC.md` and `README.md` updated; a Trellis release follows.

## Acceptance

- A fresh `trellis init` into an empty repo produces no `work-task.md`
  and an AGENTS.md whose Trellis block names good-agent's skill.
- Trellis's own tests pass and `good-agent check` exits 0 there.

## Notes

- Do this after GA0005's first release, so Trellis depends on the
  published package.

## Risks

- Repos onboarded before this change keep a stale `work-task.md`; the
  Trellis changelog says to delete it and run `init --skill`.
