# GA0010 — Release 0.2.0

## Why

PR #5 merged GA0008 (`check` honours `.gitignore`) and GA0009 (the runner
prints why a reviewer failed) into `main` at version 0.1.0, which is already
on npm, so the release run on that push skipped publishing (design section 8:
the bump is the release). The taproot adoption branch (TR01306) waits on a
release that has both fixes so it can drop its `ignore` workaround and run
its full CI once.

## Version

0.2.0, a minor. Discovery inside a git work tree now takes its candidates
from git, which can turn a failing repo green (taproot) and is a behaviour
change rather than a fix of a documented one; the reviewer failure output
adds a `model_source` field to `.meta.json`. No rule id, severity, limit or
schema changed, so nothing in the public API moved. The alias
`@taprootio/good-agent@0.1.1` depends on `good-agent >=0.1.0 <1` and needs
no bump.

## Changes

- `package.json` and `package-lock.json`: version 0.2.0.
- `CHANGELOG.md`: the Unreleased section becomes `0.2.0 (2026-11-02)`.
- `README.md` and `docs/design.md`: the status line and the sample output
  say 0.2.0, and the CI examples pin `npx good-agent@0.2 check` (the `@0.1`
  selector would exclude this release; found in external review).

## Closeout

- Gates: Trellis check, `node --test`, typecheck and `good-agent check` pass.
- Review: a mechanical version bump; one external diff round by the other
  AI tool, independent of the author. Rounds and dispositions are below.
- After the merge: confirm the release run publishes `good-agent@0.2.0` with
  provenance and creates `v0.2.0`, and that the alias job reports 0.1.1
  already on npm.
